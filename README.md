# SOC Lab – Cybersecurity Detection & Threat Hunting Environment

## Overview

This repository documents my personal Security Operations Center (SOC) laboratory built for hands-on cybersecurity practice.  

The lab is designed to simulate real-world enterprise environments for threat detection, log analysis, and incident response using industry-standard tools.


## Objectives

- Build practical SOC analyst skills through real log analysis
- Detect and investigate cyber threats in simulated environments
- Develop proficiency in SIEM tools and security monitoring
- Practice threat hunting and incident response workflows

---

## Technologies Used

- Splunk Enterprise (SIEM & log analysis)
- Wazuh (Security monitoring & alerts)
- Suricata (Network intrusion detection)
- Linux (Ubuntu Server)
- Windows VM (Event logging & testing environment)

---

## Core Skills Developed

- Security log analysis and correlation
- SSH brute-force detection and investigation
- Network traffic monitoring and alerting
- SIEM querying using Splunk Search Processing Language (SPL)
- Incident detection and basic threat hunting

---

## Lab Architecture

This lab simulates a basic enterprise environment consisting of:

- Linux server generating authentication and system logs
- Windows machine generating event logs
- Suricata monitoring network traffic
- Splunk aggregating and analyzing logs
- Wazuh providing security alerts and endpoint monitoring

---

## Key Focus Areas

- Authentication attacks (SSH brute force, failed logins)
- Network intrusion detection
- Suspicious process and activity monitoring
- Log correlation across multiple data sources
